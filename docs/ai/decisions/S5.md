## World and rendering

Use a 16x16x16 dense chunk: 4096 one-byte block IDs before metadata. A cubic
shape has ratio one and limits worst-case exposed geometry to 24576 faces.
Signed chunk coordinates are separate from checked local coordinates; no hierarchy or streaming.

The canonical script constructs a private chunk once, using a deterministic
coordinate-and-seed integer random host primitive. The formula and iteration
belong to the script. At integer z=0..2 every voxel is stone; z=3..8 forms the
transition; z>=9 is air. A bulk publication validates IDs and dimensions and
assigns content identity once. Native tests may use a reference fixture generator.

Native meshing emits only exposed faces in stable order, caches on exact content
revision/input identity, and never runs per frame. Submit the cached faces in a
bounded draw path with nearest-filtered original 16x16 stone pixels. Preserve
the existing simple face shading; add no new lighting/effect system. LOD moves
to S6 because one resident chunk does not need a distance policy.

## Scripts and simulation

Scripts execute at configuration/scenario load time, populate a private candidate,
then publish validated native chunk data and immutable native commands. Functions,
loops and conditions compose richer scenarios; no interpreter runs in frame or
server-tick loops. Failed compilation/execution never mutates the live world.
Use trusted packaged sources until the actual 0.0.3 API's execution limits are
verified; never claim a cancellation budget based on historical design prose.

Simulation, protocol validation, input sequencing, movement prediction and
reconciliation, meshing, rendering and per-tick scenario execution remain native.
World flight is authoritative XYZ. Desktop controls use mouse look, yaw-relative
WASD, Space up and Shift down, with a first-person view and a fixed clear-air
spawn. Preserve smooth S4 movement. Physics and permission gating remain S7 work after the wrapping scope moved into S6.

The protocol becomes versioned, explicitly little-endian and fixed-width before
XYZ state is sent. Reject unknown versions, invalid fields and trailing data
before state changes. Client/server share world configuration identity.
